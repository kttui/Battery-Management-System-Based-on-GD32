使用 GD30BM2016 的移植事项

                                                                                                    摘要
GD30BM2016 是一款高度集成的高精度电池监控器和保护器，该器件包含一个高精度监控系统和一个高度可配置的
保护子系统，并支持自主式或主机控制型电池平衡。主控器件在 GD30BM2016 上电时，根据系统要求对该器件进行
初始化流程配置，读取状态和数据结果。

GD30BM2016 可以做到与 BQ76952 完全 PIN2PIN 兼容，外围电路兼容设计，但寄存器、引脚定义等与 BQ76952
有略微差异。本文主要介绍了使用 GD30BM2016 时的软件移植流程，目的是配合用户更快的实现系统级应用。

1    器件连接注意事项
用户在使用 GD30BM2016 时，连接和配置必须按照下述说明使用，如果不按要求的作业，有可能会损坏保护板的元
器件，从而导致器件不能保护电芯，造成严重的后果。

连接步骤

1.   先连接电池组的动力线负极 BAT-到 PCB 板上的 BAT-；
2.   接着连接电池组的采样排线到 PCB 板上的电池采样口；
3.   最后连接电池组的动力线正极 BAT+到 PCB 板上的 BAT+；
4.   所有连接线安装好，再激活电池保护板开机，确认电池总电压与保护板输出电压相等。

断开保护板的步骤

1.   先将 PACK+至 PACK-的负载移除，然后通过指令关闭充放电 MOSFET；
2.   接着断开电池组正极的 BAT+连接线；
3.   然后拔下电池组的采样排线；
4.   最后断开电池组负极的 BAT-连接线。

未使用 CELL 的连接

对于在设计中未使用的 CELL 输入，应该与之相邻有效 CELL 输入直接短接，不可以浮空并且将 vcell_mode 寄存器
中未使用 cellx bit 设置为 0。

2      GD30BM2016 与 BQ76952 差异
GD30BM2016 和 BQ76952 硬件上可以做到完全的 pin to pin 兼容，标准的推荐电路，无需做任何 BOM 的更改。但
在引脚定义、功能和使用方法上略有差异，该文档整理了硬件、性能、寄存器等差异点，具体如下：

2.1      硬件差异

BM2016 高压部分芯片的面积大于 BQ76952，高压面积增大意味这更大的功率承受能力，对于外部浪涌冲击具有更
大的耐受特性。

2.2     性能和功能对比


2.2.1        均衡差异

      BM2016 在均衡时，均衡时序和采样时序完全数字控制错开，因此 VC1-VC16 的均衡不会影响采样结果和精
       度。BQ76952 的均衡从 VC16 取电，均衡和采样存在并行的工况，当均衡较多时，由于 VC16 的 RC 输入电
       阻，会造成测量结果偏低。
      当选择的电池串数低于 16 串时，BQ76952 每个 cell 的占空比不同，也就是说平均均衡速度会有差异，接入的
       电池串数越少该现象越明显。BM2016 每个 cell 的均衡不会把不选择的 cell 控制去除，每个 cell 的均衡占空比
       完全一致，均衡占空比只跟 loop_slow 有关，loop_slow 越大占空比越大。
      BM2016 采用数字状态机控制均衡的开关，当手动均衡命令下发后，BM2016 每次都稳定的 2ms 后打开对应
       cell 的均衡。BQ76952 采用软核的方式控制均衡的打开，手动均衡命令下发到生效有时需要 1S 才能打开均衡
       开关。

2.2.2   DSG 和 CHG 差异

   BM2016 CHG SOURCE 和 SINK 等效阻抗是 380ohm，DSG SOURCE 和 SINK 等效阻抗是 800ohm，
    BQ76952 内部等效阻抗是 2000ohm，这意味着 BM2016 开关驱动电流更大，驱动速度更快。
   BM2016 DSG 和 CHG 的控制都是跟随硬件数字状态机，用户再发送打开 MOS 命令或者关闭 MOS 命令后，约
    us 后，BM2016 会操作对应的 MOS。但 BQ76952 由于是软核，需要更多的时间控制 MOS 开关且时间不固
    定。




   DSG 和 DCHG 作为驱动状态的输出信号，BM2016 的 MOS 动作和驱动状态输出信号电平基本同步，MCU 检
    测电平可以迅速知道 MOS 动作的结果。BQ76952 需要更多的时间才能把 MOS 状态输出到引脚上。

2.2.3       采样数据处理

       BM2016 支持不同 CELLX 输入电阻的补偿，当前 BM2016 在工厂 ATE 阶段使用 20ohm 的输入电阻做校准，如
        果客户使用 100ohm 电阻（推荐值），可以直接回读 Cellx gain，将原始的 Cellx gain * 1.0013 写入到 CellX
        gain 寄存器中。如果用户为了提高浪涌能力，选择 1000ohm 的输入电阻，直接回读 Cellx gain，将原始的
        Cellx gain * 1.0049 写入到 CellX gain 寄存器中
       BM2016 和 BQ76952 的电压电流都为双 ADC 同步采样，但采样速度不同，BQ76952 的 VADC 和 CADC 最快
        采样速度为 3mS。BM2016 电压采集 VADC 和 CADC 的时钟为 1KHZ，采样周期默认为 1ms，pack/Stack/LD
        为一组轮循采样，每三个温度引脚为一组轮循采样。除非系统对获取电压速度要求很高即对采样速度要求很
        高，一般将以将 VADC 设置为 4ms，这样可以提升采样精度。

   NTC 内部采用了 18K 上拉电阻，NTC 的输入电容不要太大，建议不要超过 1nF,否则 RC 充电速度太慢会造成
    电压还没有建立稳定就采样，采样值偏低。由于 BM2016 的采样速度更快，更需要注意滤波的电容值。

2.2.4   VC0 和 VC1 低串

BM2016 和 BQ76952 的 VC0 对地都不是高压管，均需要并联稳压管到 VSS，避免充放电过程 VC0 浮动电压损坏
VC0。BM2016 可以-0.5V 到 1.2V 范围内的共模电压，CELL1 电压精度无损失。BQ76952 在-0.5V 到 0.5V 共模电
压范围内，CELL 1 电压精度无损失。BM2016 相比与 BQ76952 具有更大的模拟电压抑制，不会对于 CELL1 电压精
度有影响。

2.3.6    保护阈值与延迟的 STEP 的差异

芯片提升了 CELL 硬件保护的阈值，将保护 step 提升到 20mv，与 BQ76952 存在差异，所以计算 cov_th，cuv_th
的阈值 STEP 为 20mV，并且设置值存在一个 offset。举例，如果设置 cov_th 为 4.2V，计算值为 4200/20 -
1=209=0xD1，设置保护阈值为 0xD1。保护阈值迟滞电压也是 20mV 为一个 step。

由于内部时钟的差异，cov_delay,cuv_delay,occ_delay,ocd1_delay,ocd2_delay 延迟时间 step 为 3.9ms，与
BQ76952 的 3.3ms 不同。并且上述值存在 2 个 offset。比如设置 cov_delay 为 0，就以为发生 cov 事件
3.9*2=7.8ms 后，就会触发保护。

2.4     软件配置差异


2.4.1     通信差异

      BM2016 支持两种串行通信接口，分别为 I2C、SPI 接口。I2C 接口支持最高 400kHz 时钟速率（可选 CRC 校
       验）；SPI 接口为从接口，支持高达 2MHz 的时钟速率（可选 CRC 校验）。BM2016 在 I2C 模式下支持两个
       设备地址默认地址为 0x20，其设备地址由 SPI_MOSI 引脚决定，引 SPI_MOSI 引脚 floating 或者拉低设备地址
       为 0x20，引脚拉高设备地址为 0x22。
      BM2016 第一次上电，通信时钟时不工作，需要用通信时钟（SCL 或者 SPI_CS）唤醒，所以用户上电第一次
       发送通信 AFE 是 nack 的，第二次 AFE 才会 ack 主机的命令。
      BM2016 通信的帧格式、CHECK SUM 计算以及 CRC 计算方式和 BQ76952 有部分差异，具体的差异和示例请
       查阅 GD30BM2016 软件用户指南文档，该文档详细描述了直接子命令、不带数据子命令、带数据子命令、寄存
       器读写的 I2C/SPI 帧格式命令，CheckSum 计算、CRC 计算和相关示例。CRC 数据清零复位的逻辑与 TI 不
       同，BM2016 只有在计算 CRC 数据后才会复位 CRC，开始下一次新的计算。例如主机之前在与其他设备通
       信，之后要切换与 AFE 通信时需要先任意发送一次读或者写命令来复位 CRC。
      对于直接子命令读，BM2016 不支持一次通信连续读 16 节电芯电压，如果用户要获取电压、温度等数据，需要
       按照下面的帧格式读取（以 I02 为例），每次只能返回一个命令对应的寄存器值。
      在执行带数据的子命令或者寄存器读命令时必须等待足够的时间来让器件完成操作，再向 0x61 写完要读取的长
       度后，等待至少 200us，再发送 0x40 读指令获取数据

2.4.2     电压串数

BQ76952 上电默认为 16 节电芯工作，BM2016 默认只有 CELL1 工作，用户如果上电为 16 节，需要将
VCELL_MODE 0x8808 寄存器配置为 0xFEFF，bit 8 必须配置为 0。如果串数低于 16 串，需要将未使用的 cell 短
接，并且配置 VCELL_MODE 对应为 0。另外 CELL1 和 CELL16 必须使用，不可以将 CELL16 短接到 CELL15 上，
同理 CELL1 也不能短接到 CELL2 上，否则最低串、最高串的均衡会被影响。

2.4.4    寄存器和命令解密

     BQ76952 系统设计了寄存器解锁的 SEAL KEY，但是即使不开启 SEAL_KEY，仍然可以做寄存器的更新。
      BM2016 为了配置安全要求，必须要输入密码进入 full access 模式后，再进入 set config 模式才可以配置寄存
      器，退出 config 模式后寄存器才会生效。
     用户若使用 MCU 发送命令控制 MOS，建议要在 full access 模式下发送，例如 PDSG_TEST、PCHG_TEST、
      CHG_TEST、DSG_TEST 在 SEAL 模式下被 AFE 忽略，在 full access 模式下才可以生效。

3.1     BM2016 上电时序

GD30BM2016 的 RST_SHUT 引脚控制芯片进入 shutdown 模式，TS2 引脚下降沿将芯片从 shutdown 模式唤醒至
normal 模式，AFE 在上电后，用户需要发送通信唤醒 AFE 通信模块的时钟，在 sleep disable 模式下配置 AFE，具
体操作参考下面时序图。

3.1.1    硬件复位芯片

平则会有漏电）。也有许多用户在 WAKE UP PIN 上接入三极管，到 TS2 的信号与 WAKE PIN 信号相反，这种硬件
下 WAKE UP PIN 需要先配置为低电平。

3.5     温度配置和读取

温度配置用户可以参考下面步骤进行配置：
     根据外围电路热敏电阻的连接情况，按照寄存器定义配置对应的引脚为热敏电阻输入，同时配置是否需要打开
      电芯温度保护或者 FET 温度保护，例如选择 TS1 和 SPI_MOSI 引脚作为热敏电阻输入，需要 TS0_1 Config 配
      置为 0x50, 多功能引脚 SPI_MOSI 配置为 0x13，多功能引脚的定义查看寄存器的 Pad 章节。
     引脚配置结束后，需要配置是否使用芯片内部上拉和上拉电阻的阻值，具体查看 PAD CFG Register(0x8210)寄
      存器定义,这里配置的是所有热敏电阻的上拉源和上拉电阻，如果用户使用内部上拉 ts_res_sel[5:4]需要配置为 1
      或者 2，如果用户想使用外部上拉，ts_res_sel[5:4]要配置为 0。
     最后根据热敏电阻型号和 GD 提供的表格，计算需要写入的温度热敏电阻系数，将结果写入温度系数寄存器
      COEFF_A1_18K Register - COEFF_A4_18K Register，如果使用的是 180K 上拉电阻，写入
      COEFF_A1_180K Register - COEFF_A4_180K Register。
     配置结束后可以通过直接子命令访问读取温度, 温度单位为 0.1℃，如果用户需要获取温度引脚 ADC 采样结
      果，也可以通过带数据的子命令获取。

温度配置需要注意以下几点：
     TS1 必须默认用作温度热敏电阻，并且作为电芯温度保护，因此必须 TS0_1 Config Register 为 0x50，如果配
      置为 0x00 或者 0x40 会误报 UTC 告警，并且导致 UTD、OTD 温度告警错误无法恢复。
     如果 TS2 配用作热敏电阻，按照默认值 TS2 引脚同时也为硬件唤醒, 由于 TS2 对地有热敏电阻，芯片无法进入
      shutdown 模式这里处理和 TI 一致，如果用户要使用 TS2 引脚作为热敏电阻，还要进入 shutdown 模式，可以
      将 Power Config Register(0x8000) bit[12]：shut_ts2:烧录为 1 即 LD 唤醒，这样可以同时满足 TS2 用作热敏电
      阻且 shutdown 功能正常。
     DCHG 引脚和 DDSG 引脚在作为温度热敏电阻输入时，需要配置 0x8E2A 寄存器对应的 bit 断开 MOS 状态监测
      影子寄存器功能，并且选择为电芯温度保护。当 0x8e2a[0]=0 时，DCHG 作为 CHG 的影子信号，当
      0x8e2a[1]=1 时，DDSG 作为 DSG 的影子信号，如果作为温度输入需要配置为 1.

备注：若要获取温度 PIN 配置寄存器详细细节，请按照寄存器名称在 Register Maps 寄存器文章中查找，所有温度
读取数据寄存器如下所示。

3.6     FET 控制

MOSFET 配置和状态读取
MOSFET 支持 AFE 控制和 MCU 控制，用户根据需求配置相关寄存器，用户如果完全仅 MCU 手动模式控制 MOS，
仅需要在 Full Access 模式下发送 PCHGTEST、CHGTEST、PDSGTEST、DSGTEST 控制对应 MOS 的的开关，
通过 FET Control 命令检测 MOS 的状态。

如果用户需要 AFE 参与到 MOS 的控制，无论是 AFE 自动控制还是 MCU+AFE 半自动控制，FET 均需要按照以下
进行步骤进行配置：
1. fet_en 为 MOSFET 的总使能寄存器，通过 Manufacturing Register[fet_en]使能 MOS 总开关，也可以通过
FET_ENABLE 子命令（toggle 信号）控制 Manufacturing Register[fet_en]的信号，打开 AFE 控制 MOS 的总使能开
关；

GD30BM2016 移植事项 Rev.F          Copyright © 2025, GigaDevice Semiconductor Inc.                                    27
March 22,2026                                All Rights Reserved.
                                       www.gigadevice.com                  Application Note

2. 在使能 MOS 总开关后，进一步在 FET_OPTIONS Register 配置 FET 的详细控制（建议默认值 0x0D），如果与
用户有极低的功耗需求，在这里面也可以配置源跟随模式，在 sleep 下关闭 CHG PMUP 降低功耗；
3. 电荷泵可以提供 5.5V 或 11V 来驱动 CHG 和 DSG 引脚的栅极，用户可以通过修改 CHG_PUMP_CONTROL
Register [LVEN] 中的配置位来设置所需的电压；
4. 如果用户使能了 PCHG 或者 PDSG，必须要配置退出预充和预防的条件，否则系统一直检测不到退出条件无法切
换到正常的 CHG 或者 DSG 状态。
5. 配置完 MOS 基本功能后，用户可以配置是否选择 DFETOFF 和 CFETOFF 引脚联合控制 MOS，例如 DFETOFF
Pin Config Register 配置为 0x98， CFETOFF Pin Config Register 配置为 0x9A，当检测到引脚输入为高时，MOS
正常打开，如果配置为低时，对应的 MOS 关闭。
6. 用户可以通过 FET Status 状态实时检测 MOS 是否有打开，或者配置 DCHG Pin Config 和 DDSG Pin Config 引
脚为驱动输出信号（配置为 0x02)，监测 MOS 的真实状态。
备注：相关寄存器描述在下页。

MOSFET 子命令
如果用户设置了 host_fet_en 使能，可以通过 FET 相关的子命令控制 MOSFET 的开关。FET 控制常用的子命令有两
个，其中 FET Enable Register 命令是使能或者禁能 FET 总控制，该信号为 Toggle 信号，如果当前 fet_en 使能，发
送该子命令后 fet_en 被禁能，若 fet_en 为禁能，发送该命令后 fet_en 使能。另一个命令为 FET Control Register，
可以分别控制 PCHG、PDSG、CHG 和 DSG 信号，写 1 该 mos 禁能，写 0 该 mos 使能。建议使用 FET Control
Register 命令自主控制 mosfet，不要多种命令搭配使用，例如不要同时使用 All FETs Off Register、FET Control
Register 等不同命令控制 MOS，避免一些命令未清除导致 mos 一直被禁能。

MOSFET 未打开
用户按照上述配置和命令控制 FET 后，满足条件发现 MOSFET 未打开，需要查看 Safety Alert A/B/C, PF Alert
A/B/C/D 的状态。其次通过子命令 FET Status Register 查询 mos 当前状态，确认 MOS 是真实未打开还是测量问
题。如果用户设置了 PCHG 和 PDSG 使能，一定要配置退出 PCHG 和 PDSG 的条件。

PCHG 注意事项
如果客户需要使用 PCHG，需要设置 PRECHARGE_START_VOLTAGE 和 PRECHARGE_STOP_VOLTAGE
Register 相关寄存器，到设置阈值进入 PCHG 或者从 PCHG 状态退出，如果写 0 则默认禁止该功能。若使用
PRECHARGE 功能，则一定配置 PRECHARGE_STOP_VOLTAGE Register，避免 AFE 一致处于 PCHG 状态不能
切换至 CHG。
PDSG 注意事项
如果客户需要使用 PDSG，需要设置 PREDISCHARGE 相关寄存器，到设置时间或者阈值从 PDSG 状态退出，对应
的寄存器为 PREDISCHARGE_TIMEOUT Register 和 PREDISCHARGE_STOP_DELTA Register。如果写 0 则默认
禁止该功能，如果使能了 PDSG 功能但未配置退出条件，会导致 AFE 一直处于 PDSG 状态不能切换至 DSG。

放电时 CHG 自动打开
当大电流放电时，为了降低二极管的损耗 AFE 检测到放电电流大于 BODY_DIODE_THRESHOLD Register 阈值
（默认值为 50mA），AFE 会自动开启 CHG 管，并关闭 PCHG 管子。

DDSG 和 DCHG PIN
DDSG 和 DCHG PIN 不仅可以做低边 MOS 的驱动信号，也可以用来作为高边 MOS 的状态信号。用户可以配置
DDSG Pin Config Register[ddsg_pin_fxn]为 2，作为 DSG MOS 的影子信号。当 DSG MOSFET 打开时，DDSG 引
脚输出高电平，当 DSGFET 关闭时，DDSG 引脚输出为低电平。同理用户可以配置 DCHG Pin Config Register
[dchg_pin_fxn]为 2，作为 CHG MOS 的影子信号。当 CHG MOSFET 打开时，DCHG 引脚输出高电平，当 CHG
MOSFET 关闭时，DCHG 引脚输出低电平。

3.7     均衡使用


3.7.1      自动均衡

GD30BM201X 芯片自动均衡采用奇偶均衡的方式，禁止相邻两个均衡电芯同时开启均衡，避免相连电芯同时均衡导
致局部过热。下图是自动均衡逻辑，首先判断电池电压是否满足均衡进入的条件，满足后需要判断电芯温度和芯片内
部温度，需要注意的是 TS1 引脚默认为热敏电阻输入，必须接入电阻确认 TS1 的读数在均衡范围要求内，如果条件
均满足且没有告警事件发生，则会进入均衡状态。开始均衡后实时判断是否满足均衡退出条件或者均衡计数器时间
到，任一满足其中 1 个则会停止均衡。例如最大电芯压差为 50mV，设置均衡计数器时间为 20S，期间如果电芯压差
小于均衡停止压差，则会退出均衡。20S 后如果电芯压差仍大于 50mV 则再次进去均衡，如果小于均衡进入压差，
则不满足均衡进入条件停止均衡。

     打开均衡总开关，配置 0x8C00 BALANCING_CONFIGURATION[cb_en]为 1；
     0x8C00 BALANCING_CONFIGURATION 中的[cb_nosleep] & [cb_sleep] & [cb_rlx] & [cb_chg] 可以控制是否
      允许在不同模式下开启均衡，建议 0x8C00 配置为 0xC3;
     0x8C01 – 0x8C03 为均衡温度阈值寄存器，用户按照使用要求自行配置；
     0x8C06 – 0x8C09 为充电模式均衡电压寄存器，0x8C0A – 0x8C0C 为空闲模式均衡电压寄存器用户按照使用要
      求自行配置；
     0x8C04 CB_BALANCE_INTERVAL Register 为均衡时间计数器，默认 20S 均衡时间到后会再次判断均衡条
      件，如果满足会再次自动打开均衡；
     配置均衡最大电芯节数 0x8C05 CB_BALANCE_MAX_CELLS，建议配置为 0x08；
     配置充电电流阈值 CHG_CURRENT_THRESHOLD(0x8C14)和放电电流阈值 DSG_CURRENT_THRESHOLD
      (0x8C12)寄存器；
     配置结束后退出 Config 模式，满足均衡条件后均衡会立即生效。

例如用户电池在充电、空闲状态运行均衡，BMS 通过比较实时电流与充放电电流阈值加工当前电池的状态，放电电
流阈值寄存器为 DSG_CURRENT_THRESHOLD（默认值为 100userA），当放电电流大于放电电流阈值，AFE 认
为处于放电状态停止均衡。充电电流阈值寄存器 CHG_CURRENT_THRESHOLD（默认值为 50userA），当充电电
流大于充电电流阈值，AFE 认为充电状态。

Register 获取当前均衡的电芯，如果当前电芯在均衡，则对应的 bit 置 1，均衡停止后对应的 bit 置 0。注意在自动均
衡模式下该寄存器只读，禁止写入。用户也可以读取 0x208 获取均衡总时间，也可以读取带数据的子命令 0x210 –
0x24C 和 0x15C 获取单节电芯的均衡时间，均衡计数器时间到后会更新均衡时间。

下面是 GD32BM2016 手动均衡的代码示例，输入参数是用户需要均衡的电芯，在代码中首先将电芯编号和均衡子命

均衡示例
#define MASK16_EVEN                               0x000154AA        // (0xAAAA& 0x1FF)|(0xAAAA >> 9) & 0x7F) << 10
#define MASK16_ODD                                0x000A955         // (0x5555& 0x1FF)|(0x5555 >> 9) & 0x7F) << 10
void bm2016_manual_cellbalance (uint16_t cell_number,cb_type_t cb_mode)
{
// Trigger manual equalization with the rising edge
      bm2016_subcommands_withdata(CELL_BALANCING_ACTIVE_CELLS, 0x000000, W4);
      delay_1ms(500);
      uint32_t cbcell_temp;
      /* low 9 bits (cells 1..9) + shifted high 7 bits (cells 10..16) */
      cbcell_temp = (cell_number & 0x01FFu)                                   /* bits 0..8   -> 0..8 */
                      | (((cell_number >> 9) & 0x7Fu) << 10);              /* bits 9..15 -> 10..16, bit9 = 0 */
      switch (cb_mode) {
                 case CB_ODD:
                            /* handle odd balancing */
                      cbcell_temp = cbcell_temp & MASK16_ODD;
                     bm2016_subcommands_withdata(cbcell_temp, cbcell_temp, W4);
                            break;
                 case CB_EVEN:
                            /* handle even balancing */
                            cbcell_temp = cbcell_temp & MASK16_EVEN;
                     bm2016_subcommands_withdata(cbcell_temp, cbcell_temp, W4);
                            break;
                 case CB_STOP:
                            /* handle stop balancing */
                        bm2016_subcommands_withdata(CELL_BALANCING_ACTIVE_CELLS, 0x000000, W4);
                            break;
                 default:
                            bm2016_subcommands_withdata(CELL_BALANCING_ACTIVE_CELLS, 0x000000, W4);
                            break;
                 }
}

3.8     保护功能

DSG/CHG 保护设置
保护生效分为以下步骤：
1.    首先设置保护条件，包括阈值、保护滤波时间、恢复时间等；具体的保护条件查看 Register Maps 中的 Protect
      章节。
2.    其次需要使能保护寄存器：ENABLED_PROTECTIONS_A Register、ENABLED_PROTECTIONS_B
      Register、ENABLED_PROTECTIONS_C Register，这些寄存器中定义了具体的保护，例如过压、欠压、过
      流、过温等。
3.    如果用户要使用二次保护功能，配置也类似，先配置二次保护条件，在 ENABLED_PF_A Register、
      ENABLED_PF_B Register、ENABLED_PF_C Register、ENABLED_PF_D Register 中使能具体的故障保护，
      同时在 Manufacturing Register 和 PROTECTION_CONFIGURATION Register 选择是否是否使能永久失效保护
      和对应动作。
4.    完成上述步骤后，还需配置 CHG_FET_PROTECTIONS_A Registers、CHG_FET_PROTECTIONS_B
      Registers、CHG_FET_PROTECTIONS_C Registers、DSG_FET_PROTECTIONS_A 、
      DSG_FET_PROTECTIONS_B Register、DSG_FET_PROTECTIONS_C Register，才能将 MOS 控制与故障
      关联起来，完成上述步骤才能在发生故障时断开 MOS，实现保护功能。例如要使欠压保护生效，需要设置欠压
      保护条件 CUV_THRESHOLD、CUV_DELAY、CUV_RECOVERY_HYSTERESIS Register，然后使能
      ENABLED_PROTECTIONS_A Register[cuv_prot_en]，并写 DSG_FET_PROTECTIONS_A
      Register[dsg_fet_cuv_en]为 1。
5.    注意 OCVL、OCDL、SCDL 中的 decrement delay time 设置值必须小于 recover time 设置值。

MOSFET 未断开
发生故障后对应的 MOSFET 未断开进行保护，用户直接子命令查询 Safety Alert A/B/C, PF Alert A/B/C/D 的状态。
其次通过子命令 FET Status Register 查询 mos 当前状态，确认 MOS 是真实未断开还是测量问题。如果 MOS 未断
开，查询保护条件、ENABLED_PROTECTIONSABC、CHG_FET_PROTECTIONSABC、
DSG_FET_PROTECTIONS 的配置。

3.9     中断 ALERT 处理

当使用 ALERT 信号作为中断时候，当发生故障后芯片可以输出有效电平给到 MCU，触发故障中断给到 MCU，具体
中断引脚配置可以参考引脚复用章节的介绍。针对中断使能相关的配置主要涉及到以下寄存器：
     POWER_CONFIG (0x8000) BIT14 配置为 1：可以用清除命令恢复 Alert 引脚电平。
     Alert Pin Config Register 需要配置为 2 = ALERT.
     DEFAULT_ALARM_MASK Register( 0x881E)，选择 Alert 输出有效电平的故障源
     SF_ALERT_MASK_A (0x8815)
     SF_ALERT_MASK_B (0x8816)
     SF_ALERT_MASK_C (0x8817)
     PF_ALERT_MASK_A (0x8818)
     PF_ALERT_MASK_B (0x8819)
     PF_ALERT_MASK_C (0x881A)
     PF_ALERT_MASK_D (0x881B)

查询中断状态涉及直接命令 ALARM_STATUS (0x62)、ALARM_RAW_STATUS (0x64)。通过将 SF_ALERT 和
PF_ALERT 的对应比错误 mask 的 bit 置为 1，当发生对应终端后，ALERT 就会输出有效电平。用户可以通过查询
ALARM_STATSU 查询是哪些故障造成了 ALERT 事件。

当故障消失后，ALERT 信号重新回到无效状态。如果之前故障未消失，ALERT 信号仍继续断言，如果用户希望继续
查询是否有其他故障发生，可以查询 ALARM_STATUS 和 ALARM_RAW_STATUS 来获知是否有新的中断发生。用
户可以通过对 ALARM_STATUS 对应的 bit 写 1 的动作清除掉 ALARM_STATUS，ALARM_RAW_STATUS 只有故
障消失才可以自动清零。

4    初始化流程
器件的初始化主要是对于一些重要参数进行配置，其中包含系统参数（MOSFET 控制，采样速率，低功耗模式
等），校准（如采样电阻值），引脚重新映射（NTC，GPIO 等），一次和二次保护参数以及均衡等。器件初始化流
程主要包括 6 部分，具体如下：
1.   将器件进入 seal 模式，首先 unseal 后再进入 full access，进入 set_cfgupdate，此时才可以对于寄存器进行操
     作。
2.   系统寄存器配置，寄存器基地址 0x80xx，查看寄存器表 sysc 的部分，主要用来设置系统低功耗模式，配置
     deepsleep，shutdown，sleep 模式下电荷泵，MOSFET 控制，时钟等参数。设备内部 LDO，REG0，REG1，
     REG2 的使能与电压, MOSFET 控制方式。
3.   保护相关参数，寄存器基地址 0x88xx，查看寄存器表格 protect 的部分，主要包含 cell mode（串数），COV，
     CUV，OCC，OCD1，OCD2，SCD，OTC，OTD，UTC，UTD 等相关一次保护，以及对应的二次保护参数，
     部分 MOSFET 保护的管关联控制。
4.   引脚映射，寄存器基地址 0x82xx，查看寄存器表格 pad 的部分，主要涉及到 TSx 的（上拉电阻和使能），
     CFETOFF，DFETOFF，DDSG，DCHG，SPI_MOSI，ALERT 等引脚的 GPIO 或者 NTC 的配置状态。
5.   均衡相关的参数，寄存器基地址 0x8Cxx，查看寄存器表格 cb 的部分，主要包含均衡使能，均衡个数，均衡最
     小电压，均衡最小差值等。
6.   校准参数，寄存器基地址 0x84xx，查看寄存器表格 adc 的部分。

需要注意的是 GD30BM2016 大部分寄存器都已经在工厂实现了校准，不需要用户做校准。采样电阻是客户自行根据
电流选择的，需要设置 ccgain。上拉电阻温度系数需要和 NTC 类型和组织进行相应的配置，这个部分会推荐默认
值，客户初始化自行加载。以上参数配置没有顺序要求，配置完这些参数后，直接执行 exit_cfgupdate，配置就可以
生效。

5.1           直接命令函数

}

5.6       CheckSum 校验

Checksum 计算方法为累加块地址寄存器中写入的所有数据，计算得到数据和后，将高 8 位右移后再与第八位相
加，循环该步骤直到结果小于等于 0xFF，再用 0xFF 减去该结果最终所得为 checksum 校验值。
/*!
      \brief              checksum calculates
      \param[in] ptr: checksum data
                           len: checksum length
      \param[out] none
      \retval             checksum result
*/
unsigned char checksum_calculate(unsigned char *ptr, unsigned char len)
{
      unsigned char i=0;
      uint32_t checksum = 0;


      while(i<len){
               checksum =checksum + ptr[i];
               i++;
      }
      while (checksum>0xff){
               checksum = (checksum >> 8) + (checksum & 0x000000ff);
      }
      checksum = 0xff - checksum;
      return(checksum);
}
