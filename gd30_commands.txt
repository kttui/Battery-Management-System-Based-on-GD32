Application Note
Commands and Subcommands

                                                                               ABSTRACT
The GD30BM2016 device supports direct commands and subcommands. Direct commands are single-byte, while
word commands are two-byte. Direct commands are accessed using a 7-bit command address sent from the
host via the device's serial communication interface, triggering operations, providing data values to be written
to the device, or instructing the device to report data to the host. Subcommands are additional commands
accessed indirectly through a 7-bit command address space and provide block data transfer functionality.

1.16 Battery Status Register

Address Offset: 0x12
Field                  Bits       Default     Type       Field Description
                                                         This bit indicates whether or not the device is presently in SLEEP
                                                         mode.
sleep                  [15:15]    0x0         RO
                                                         0 = Device is not in SLEEP mode.
                                                         1 = Device is in SLEEP mode.
                                                         This bit is set when shutdown is pending because the command
                                                         was received or the RST_SHUT pin was asserted for at least one
sd_cmd                 [13:13]    0x0         RO         second.
                                                         0 = Shutdown due to command or pin is not pending.
                                                         1 = Shutdown due to command or pin is pending.
                                                         This bit indicates whether or not an enabled Permanent Fail fault
                                                         has triggered.
pf                     [12:12]    0x0         RO
                                                         0 = No Permanent Fail fault has triggered.
                                                         1 = At least one Permanent Fail fault has triggered.
                                                         This bit indicates whether or not an enabled safety fault is triggered.
ss                     [11:11]    0x0         RO         0 = No safety fault is triggered.
                                                         1 = At least one enabled safety fault is triggered.
