Application Note
Register Maps

                                                                              ABSTRACT
RAM registers mainly contain system parameters, calibration, pin remapping (NTC, GPIO, etc.), primary and
secondary protection parameters, as well as balancing registers. Sysc refers to system registers, which include
operating modes, communication methods, LDO output, MOSFET control, etc. Pad is related to the parameter
settings for multi-function pin multiplexing, with a base address of 0x8200. Adc pertains to calibration-related
parameter settings, most of which have already been calibrated at the factory. Protect includes all primary and
secondary protection-related parameter settings. CB refers to parameter settings related to balancing and load
detection.
